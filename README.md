## ASCII Torus

This project was inspired by the idea of contemporary art and the question: what is contemporary art? Can it be a digital donut? Here, a simple ASCII torus spins in your terminal or browser, exploring the boundary between code, art, and visual experience.

### Variants
- **Terminal (Node.js)**: Run using `node torus-cli.mjs` or simply `make run`.
- **Browser (HTML/JS)**: Open `index.html` directly in your browser.

### Features
- **Unified Engine**: Both versions share the exact same math logic located in `assets/js/engine.js`.
- **Smart Rendering**: Optimized for terminal size and browser window.
- **Modern UI**: Web version includes a visit counter, up-time timer, and premium aesthetics.
