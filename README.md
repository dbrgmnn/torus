# Torus

Spinning ASCII torus for browser and terminal.

**Tech:** HTML, CSS, Vanilla JS (ESM), Node.js

### Run
- **Web**: Open [torus](https://dbrgmnn.github.io/torus/)
- **Terminal**: `make run` (requires Node.js)
